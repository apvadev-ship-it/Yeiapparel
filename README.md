# YEI Editorial Boutique

Crea una página web e-commerce premium para la marca de moda femenina **YEI**, tomando como referencia visual y estructural la imagen/moodboard proporcionada.

### 1. CONCEPTO DE MARCA

YEI es una marca de ropa femenina que representa:

- Elegancia contemporánea
- Feminidad sofisticada
- Estética clásica
- Minimalismo editorial
- Exclusividad accesible
- Moda atemporal con detalles modernos

La web NO debe parecer una plantilla genérica de Shopify.

Debe sentirse como una **revista de moda editorial convertida en tienda online**, con una identidad visual propia, sofisticada y memorable.

La dirección de arte debe combinar estética **Old Money + editorial fashion + minimalismo contemporáneo + lujo latinoamericano**.

---

### 2. DIRECCIÓN VISUAL

Usar como base la estética del mockup proporcionado.

Paleta principal:

- Marrón chocolate profundo: #351A17
- Terracota / rojo quemado: #B74F3F
- Rosa nude / beige rosado: #EBD8CF
- Marfil cálido: #F7F3EE
- Negro editorial: #171313

La paleta debe utilizarse con mucho espacio negativo.

El chocolate debe funcionar como color institucional.
El terracota debe utilizarse para CTA, detalles y elementos interactivos.
El nude debe dominar grandes superficies.
El marfil debe utilizarse para fondos limpios.

Evitar colores saturados, gradientes artificiales, sombras excesivas y efectos típicos de templates.

---

### 3. TIPOGRAFÍA

Combinar dos familias tipográficas:

**Display / títulos:**
Una serif editorial de alto contraste, elegante y femenina, similar a Didot, Bodoni o Cormorant Garamond.

**Textos / navegación:**
Una sans-serif limpia, moderna y minimalista, similar a Inter, Helvetica Neue o Montserrat.

Los titulares deben tener mucho protagonismo.

Ejemplo:

NEW 2026
COLLECTION

La palabra o número importante puede utilizar terracota para crear contraste.

Usar tracking amplio en textos pequeños y etiquetas.

---

# 4. HEADER

Crear un header elegante y minimalista.

Desktop:

- Logo YEI centrado
- Menú izquierdo:

  - NUEVA COLECCIÓN
  - MUJER
  - VESTIDOS
  - TOPS
  - PANTALONES

- Menú derecho:

  - Buscar
  - Cuenta
  - Wishlist
  - Carrito

El header debe ser inicialmente transparente sobre el hero.

Al hacer scroll debe convertirse en un header sticky con fondo marfil ligeramente translúcido.

Crear microanimaciones suaves en hover.

---

# 5. HERO PRINCIPAL

Crear un hero editorial de pantalla completa.

Utilizar una fotografía de campaña de varias modelos vestidas de blanco, con estética de fotografía de moda premium.

La composición debe ser muy similar al mockup:

- Fondo claro
- Modelos posicionadas de forma editorial
- Mucho espacio negativo
- Logo YEI
- Pequeños textos decorativos
- Tipografía serif
- Elementos gráficos minimalistas

Agregar un pequeño copy superior:

COMODIDAD ETERNA

Y debajo una llamada visual:

YEI

NEW COLLECTION 2026

CTA:

DESCUBRIR COLECCIÓN

El botón debe ser minimalista, rectangular y elegante.

Agregar una animación sutil de entrada de las modelos, textos y logo al cargar.

---

# 6. BARRA DE IDENTIDAD

Debajo del hero colocar una banda horizontal color chocolate.

Dentro de ella colocar repetidamente elementos de identidad:

YEI ✦ POLO CLASSICS ✦ YEI ✦ POLO CLASSICS ✦

Debe funcionar como un elemento gráfico de branding, no como una sección convencional.

En móvil debe convertirse en una cinta horizontal animada que se desplace lentamente.

---

# 7. SECCIÓN NEW COLLECTION

Crear una sección editorial titulada:

NEW 2026
COLLECTION

Diseño basado en composición asimétrica.

En lugar de utilizar una cuadrícula convencional, crear una composición tipo editorial:

- Una imagen central grande
- Dos imágenes pequeñas a la izquierda
- Dos imágenes pequeñas a la derecha

Las imágenes deben tener bordes y esquinas especiales inspirados en el mockup.

Al hacer hover:

- zoom muy sutil
- overlay translúcido
- nombre de la prenda
- CTA "VER PRODUCTO"

El resultado debe parecer una página de revista de moda.

---

# 8. BANNER CTA

Crear una franja terracota con:

✦ PRUÉBALA SIN SALIR DE CASA ✦

Botón:

AQUÍ

Debe funcionar como llamada a la acción para incentivar la compra.

Al hacer hover, el botón debe invertir suavemente sus colores.

---

# 9. SHOP NEW

Crear una sección de productos:

SHOP NEW

Utilizar un carrusel horizontal elegante.

Mostrar 4 productos en desktop.

Cada tarjeta debe contener:

- Fotografía del producto
- Nombre
- Precio
- Variantes disponibles
- Botón añadir al carrito
- Icono wishlist

No utilizar las típicas tarjetas de ecommerce con sombras.

Las imágenes deben tener protagonismo.

Al pasar el cursor:

- cambiar ligeramente la fotografía
- mostrar segunda imagen del producto
- aparecer CTA "VER PRODUCTO"

Agregar flechas laterales minimalistas.

---

# 10. QUIERES VER MÁS

Después del carrusel incluir:

✦ QUIERES VER MÁS ✦

Utilizar una composición editorial en lugar de un botón convencional.

# 15. CARRITO

Crear carrito lateral tipo drawer.

Cuando el usuario agregue un producto, el carrito debe abrirse suavemente desde la derecha.

Mostrar:

- Fotografía
- Producto
- Talla
- Cantidad
- Precio
- Eliminar

Y al final:

SUBTOTAL

COMPRAR AHORA

El checkout debe sentirse limpio y premium.

---

# 16. ANIMACIONES

Las animaciones deben ser sofisticadas y discretas.

Utilizar:

- Fade-in
- Parallax ligero
- Text reveal
- Image reveal
- Hover zoom
- Smooth scrolling
- Transiciones de 300–600 ms
- Aparición progresiva de elementos

No utilizar animaciones exageradas.

La sensación debe ser:

**fashion editorial, no página tecnológica.**

---

# 17. RESPONSIVE DESIGN

Diseñar primero pensando en desktop, pero construir una experiencia móvil excelente.

En móvil:

- Header compacto
- Logo centrado
- Menú hamburguesa
- Carrito visible
- Hero vertical
- Carruseles táctiles
- Imágenes grandes
- Tipografía correctamente escalada
- Botones fáciles de pulsar

La experiencia móvil debe conservar la estética editorial del diseño original.

---

# 18. DETALLES DE UI

No utilizar:

- Cards genéricas
- Gradientes modernos
- Glassmorphism excesivo
- Sombras fuertes
- Botones redondeados tipo SaaS
- Layouts genéricos de Shopify
- Iconos gigantes
- Exceso de texto

Sí utilizar:

- Bordes finos
- Espaciado generoso
- Serif editorial
- Composiciones asimétricas
- Fotografías grandes
- Tipografía protagonista
- Microinteracciones
- Elementos gráficos de inspiración vintage
- Detalles en terracota
- Fondos nude y chocolate

---

# 19. SEO Y ESTRUCTURA

La web debe estar preparada para SEO.

Crear correctamente:

- H1
- H2
- Meta titles
- Meta descriptions
- URLs amigables
- Alt text para imágenes
- Schema de productos
- Open Graph
- Optimización de imágenes
- Lazy loading

---

# 20. PERFORMANCE

Optimizar para:

- Carga rápida
- Imágenes WebP/AVIF
- Lazy loading
- Responsive images
- Animaciones optimizadas
- Código limpio
- Excelente Core Web Vitals

---

# 21. PERSONALIDAD FINAL

La página debe transmitir inmediatamente:

**"YEI no es otra tienda de ropa. Es una marca de moda con identidad."**

Debe sentirse como una mezcla entre:

**editorial de Vogue + boutique de lujo + e-commerce moderno + estética Old Money.**

La referencia visual proporcionada debe utilizarse únicamente como inspiración de composición, dirección de arte y jerarquía visual.

No copiar literalmente la interfaz.

Crear una experiencia original, elegante, femenina, sofisticada y comercialmente efectiva.

Priorizar siempre:

**IDENTIDAD DE MARCA → EXPERIENCIA → PRODUCTO → CONVERSIÓN.**
